# MVP Book Tracker

## Use Case: Добавление книги в коллекцию

**Актор:** Читатель

**Предусловие:** Пользователь авторизован.

**Основной сценарий:**
1. Пользователь открывает страницу «Коллекция» (`/`)
2. Нажимает «Добавить книгу»
3. Вводит название и автора
4. Выбирает статус «Хочу прочитать»
5. Сохраняет

**Результат:** Книга появляется в коллекции со статусом.

**Альтернативный сценарий:** Книга уже есть — показывается предупреждение.

## Границы MVP
**Входит:** коллекция, статусы (хочу/читаю/прочитано), рейтинги 1–5, базовая рекомендация по жанру, авторизация (заглушка).
**Не входит:** соцфункции, импорт из Goodreads, реальный бэкенд, платные API.
